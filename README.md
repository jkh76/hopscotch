# 땅따먹기 (Hopscotch)

어린 시절 흙바닥에서 하던 **돌 튕기기 땅따먹기**를 웹 게임으로 옮긴 프로젝트입니다.
돌을 세 번 튕겨 내 땅으로 돌아오면, 돌이 지나간 자리만큼 내 땅이 넓어집니다.

- 버전: **v0.6 (2026-11-23)**
- 플레이: `index.html`을 브라우저로 열면 바로 시작 (GitHub Pages로 배포 가능)
- 인원: 2~4명, 자리마다 사람 / AI(쉬움·보통·어려움) 선택

## 게임 방법

1. **시작 설정**: 경기장 모양(사각형/원), 크기(150·200·250cm), 인원과 플레이어 종류, 변수 요소를 고릅니다.
2. **선플레이어 룰렛**: 룰렛으로 첫 차례를 정하고, 이후 번호 순서대로 돌아갑니다.
3. **본진**: 한 뼘(22cm) 크기에서 시작합니다.
   - 사각형: 네 꼭짓점의 1/4 원
   - 원형: 동서남북 테두리에 붙은 반원
   - 시작 자리는 무작위이고, 2인이면 서로 마주 보는 자리에 배치됩니다.
4. **내 차례**
   1. 내 땅 안을 클릭해서 돌을 놓습니다.
   2. 마우스로 방향을 가리키고 클릭하면 방향이 고정됩니다 (다시 클릭하면 풀림, ←→ 키로도 조절).
   3. **두 번 클릭**으로 튕깁니다 (버튼 / 막대 클릭 / Space).
      - ① 강도: 0~100을 오가는 막대를 보고 클릭하면 그 자리가 고정 표시됩니다.
      - ② 정확도: 계속 움직이는 막대를 고정 표시에 맞춰 한 번 더 클릭합니다. 표시 주변에 퍼펙트(±1.5%, 노랑)·정상(±5%, 민트)·작은 삑사리(±10%, 주황) 구간이 색으로 나옵니다. Esc로 첫 클릭 취소.
   4. 1·2번째는 내 땅 **밖**에, 3번째는 내 땅 **안**에 멈춰야 성공입니다.
5. **성공**하면 시작점 → 1번 → 2번 → 도착점을 이은 모양만큼 빈 땅이 내 땅이 됩니다.
   - 땅을 얻은 뒤 내 땅에 완전히 둘러싸인 빈 곳(구멍)은 자동으로 내 땅이 됩니다. 벽이나 다른 사람 땅에 닿은 빈 곳은 그대로 둡니다.
6. **보너스 뼘**: 성공한 턴에 한 번, 내 땅 경계에서 22cm 이내로 선을 그어 내 땅·테두리와 함께 막히는 빈 땅을 가져옵니다 (건너뛰기 가능).
   - 가장 좋은 자리를 깜빡이는 점으로 알려 줍니다.
   - 선을 그으면 미리보기와 함께 확인 창이 뜨고, **가져가기 / 다시 긋기**를 고릅니다.
7. **잡아먹기**: 보너스 뼘 선의 끝이 다른 플레이어 땅에 닿으면 그 플레이어의 땅을 **모두** 빼앗고, 그 플레이어는 탈락합니다.
   - 한 턴에 한 명만 잡을 수 있고, 선이 제3자의 땅을 지나가면 안 됩니다.
   - 닿을 수 있는 상대가 있으면 빨간 선으로 깜빡여 알려 줍니다. 2인전에서는 잡는 순간 승리합니다.

## 실패 조건

- 경기장 테두리에 닿음
- 돌이 선(경계)에 걸쳐 멈춤
- 남의 땅에 들어가거나 경로가 남의 땅을 지나감
- 1번째에 내 땅을 못 벗어남 / 2번째에 미리 돌아옴 / 3번째에 못 돌아옴
- 경로가 8자로 꼬임 (단, **교차점이 내 땅 안이면 실패 아님**)

## 변수 요소 (설정에서 켜고 끄기)

| 변수 | 내용 |
| --- | --- |
| 손 떨림 | 조준 방향만 흔들림. 강도 30 이하 ±1°, 강도 100에서 ±6°. 퍼펙트면 흔들림 없음 |
| 게이지 가속 | 강도 막대 속도가 들쭉날쭉해서 원하는 값에 멈추기 어려움. 정확도 막대는 강도 막대 기본 속도의 0.5배로 일정함 |
| 삑사리 (정확도 클릭) | 정확도 오차(게이지 전체 길이 기준)로 판정. ±5% 이내 정상, ±10% 이내 작은 삑사리(방향 3~5°, 힘 85~95%), 그 밖은 큰 삑사리(방향 15~20°, 힘 30~60%, 돌이 휨). 표시보다 왼쪽에서 누르면 왼쪽, 오른쪽이면 오른쪽으로 틀어짐. 끄면 한 번 클릭 |
| 퍼펙트 3D 연출 | 퍼펙트가 나면 카메라가 돌 뒤로 내려가 3D로 따라가고(느린 화면), 멈추면 다시 위로 올라옴. 화면을 탭하면 건너뛰기. AI 빠르게 보기를 켜면 AI 차례는 생략 (Three.js) |
| 땅 질감 | 모래(마찰 1.5배), 자갈(1.25배, 돌이 휨), 단단한 땅(0.7배) 구역이 무작위 배치 |

## 화면 꺼짐 방지

게임 화면이 열려 있는 동안 휴대폰 화면이 어두워지거나 꺼지지 않습니다 (Screen Wake Lock, 첫 터치 뒤 적용). 지원하지 않는 브라우저에서는 그냥 무시됩니다.

## 끝나는 조건

- 한 명만 남으면 그 플레이어가 바로 우승합니다.
- 그 전에 빈 땅이 5% 이하로 남거나, 남은 플레이어 모두가 연속 3턴 실패하거나, 60라운드가 지나면 끝나고, 점유율이 가장 높은 플레이어가 우승합니다 (동점이면 성공 횟수가 적은 쪽). 탈락한 플레이어는 늦게 탈락한 순서로 뒤에 순위가 매겨집니다.

## 화면 조작

- **확대·축소**: 마우스 휠, 두 손가락 핀치, 오른쪽 아래 `+` / `−` / `전체` 버튼
- **화면 이동**: 마우스 오른쪽(또는 휠) 버튼 드래그, 두 손가락 드래그
- 차례가 바뀌면 전체 화면을 보여준 뒤, 이번 플레이어의 땅 쪽으로 자동 확대됩니다.
- 3번째 튕기기나 선에 아슬아슬하게 닿을 때는 슬로모션과 확대 연출이 나옵니다.
- PC, 태블릿, 휴대폰 가로·세로 화면을 지원합니다.

## 기술

- 단일 HTML 파일 (바닐라 JavaScript + Canvas)
- [GSAP 3](https://gsap.com/) (CDN) — 애니메이션. 불러오지 못해도 게임은 동작합니다.
- Web Audio API로 효과음 직접 합성
- 폰트: Google Fonts `Jua`
